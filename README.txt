# TATATSHU — Free Static Website

This is a simple static clothing-brand website. It needs no paid hosting or backend.

## Publish for free
1. Create a GitHub account.
2. Create a new public repository, e.g. `tatatshu`.
3. Upload `index.html` and the `assets` folder.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. GitHub will give you a free `github.io` website address.

## Before launch
- Replace the WhatsApp link in `index.html` with your own number.
- Replace the Instagram link.
- Confirm product price, sizes, shipping and return policy.
- Check trademark availability for TATATSHU before investing in packaging/labels.
